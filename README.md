Calculation module components and objective:
Calculate payroll based on hours worked compared to employee pay rates
Implement methods to calculate gross pay, deductions, and net pay that varies between employees
Interact with the data base to pull different employee payrates and other info
Check with database to make sure the info going into each calculation makes sense, check inputs and outputs to make sure there are no incorrect or impossible numbers used

Database module component:
Store employee information that was gathered via the UI component, transfer employee information as needed to other modules.  
Store the different pay rates for different types of employees, assign based on paygrade
Post calculation, store final pay numbers + separate overtime numbers
Test to make sure data types make sense
Test to make sure the other modules are not handing it impossible data types

Time tracking module: 
Communicate with database to hand it accurate time tracking information, and separate normal hours reported from overtime hours reported.  
Communicate with UI module to accept reported hours from specific employees
Test to make sure the times make sense and no one is having improper hours recorded

UI module: 
Prompt the user to input necessary information with an easy to use design
Communicate primarily with time tracking and database modules 
Test for input to make sure the user is giving the correct info types
test for security to make sure that improper users cannot access information that is not theirs via authentication and input sanitization
